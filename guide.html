GETTING STARTED

血圧記録くんの使い方

最初の記録から、振り返り、CSVの控えまで。Android版とWeb版の共通の流れと、Web版ならではの注意点をご案内します。

このページの内容

  1. 記録する
  2. 履歴を見る
  3. 分析を見る
  4. バックアップ・復元
  5. カメラで入力する
  6. ホーム画面へ追加する
  7. オフラインで使う

01 / RECORD

測定した値を記録する

  1. 血圧計で測定した最高血圧・最低血圧を入力します。脈拍とメモは任意です。
  2. 測定日時を確認します。今の値なら現在日時を、過去の記録なら日時を指定します。
  3. 朝・昼・夜の時間帯を選びます。「自動」は測定時刻から判定します。
  4. 内容を確認し、Android版は「記録する」、Web版は「この記録を保存」を押します。

日時・時間帯も、測定したときのものになっているか確認してください。画面を閉じる前に保存し、保存していない入力が記録として残るとは考えないでください。

02 / HISTORY

履歴で確かめる

下部の「履歴」を開くと、保存済みの記録を日付順に確認できます。時間帯を絞って、朝だけ・夜だけの記録を見ることもできます。

値や日時を間違えた場合は対象の記録を編集し、不要な記録は削除できます。削除を実行する前に対象を確認してください。Web版ではブラウザやURLを変えると、同じ履歴が出るとは限りません。

03 / ANALYSIS

統計とグラフで振り返る

「分析」で時間帯と集計期間を選ぶと、平均・最大・最小や前回比を確認できます。月・四半期では前年の同じ時期との比較も選べます。比較する期間にデータがなければ、前年の比較結果は表示できません。

グラフへ切り替えると、選択した期間の変化を見られます。平均／範囲を切り替えたり、表示範囲を前後へ移動したりできます。期間サマリーは、その表示範囲・時間帯の記録を集計します。

統計や矢印は記録の変化を示すものです。正常・異常を診断する判定ではありません。健康上の判断は医療専門家にご相談ください。

04 / BACKUP

CSVの控えを残す

手動バックアップ

  1. 「設定」のバックアップ・復元の項目を開きます。Web版の見出しは「バックアップと復元」です。
  2. 標準CSVのバックアップ操作を選びます。
  3. ファイルを保存します。Web版は対応ブラウザで保存先を選び、非対応の場合は通常のダウンロードになります。
  4. ファイルが保存先にあることを確認します。ブラウザ内の記録とは別のファイルです。

CSVにはメモも含まれ、暗号化されていません。保存先と共有相手に注意してください。元の標準CSVをExcel等で編集すると検証できなくなる場合があるため、復元用はそのまま保管し、閲覧・編集にはコピーを使うことをおすすめします。

Web版の自動バックアップ

初期状態はOFFです。対応ブラウザで説明を確認し、自動バックアップをONにして保存先を選びます。次の新しい記録が正常に保存された後から、その時点の全記録で同じCSVファイルを上書きします。

編集・削除・復元や他形式取り込みでは自動更新しません。その後は手動で控えを保存してください。保存先の許可が切れるなど、更新に失敗したときは設定で保存先・権限を確認します。失敗しても、保存できた本体記録は取り消しません。

自動バックアップ非対応のブラウザでは、手動の標準CSVを利用してください。「端末内データの保護」も、サイトデータの明示削除や端末の故障を防ぐ保証ではなく、バックアップの代わりにはなりません。

復元・他形式取り込み

標準CSVを選び、件数・期間・同一記録・競合を確認してから復元します。復元は既存記録へ追加する方式で、既存の異なる内容を自動上書きしません。他のアプリのCSV／TSVは「他形式からのデータ取り込み」で、読み取り形式や列・時間帯を割り当て、プレビューを確認して取り込みます。

Android版とWeb版には標準CSVの互換処理がありますが、全環境での移行を保証するものではありません。移行前のCSVと元端末の記録は、移行先で内容を確認するまで残してください。Web版の保存領域はブラウザ・プロファイル・URLごとに異なり、別環境へ自動同期されません。

05 / CAMERA

カメラで入力を補助する

  1. 記録画面のカメラ入力を開き、必要なときにカメラを許可します。Web版は「カメラ読取」から開けます。
  2. 液晶全体がガイド枠内に入るようにします。反射を避け、近づけすぎず、ピントが合う距離を探します。
  3. 撮影し、端末内の読み取り処理が終わるまで待ちます。
  4. 候補と血圧計の表示を見比べます。正しいことを確かめてから「入力欄へ反映」を押します。
  5. 必要な値を手で修正し、測定日時・時間帯を確認して通常の保存操作をします。

カメラを拒否・キャンセルしても手入力で利用できます。Web版は「画像を選ぶ」から読み込む方法もあり、認識は端末内で行います。元の画像ファイルを消去する機能ではありません。

ピント調整はAndroid版とWeb版で異なります。Android版はタップ位置をフォーカスへ渡します。Web版は対応カメラの連続オートフォーカスを補助的に有効にする方式で、タップした位置へのピント指定を保証しません。

時計・メモリ番号などを誤って拾う場合もあります。読めない項目や誤った候補は手で確認・修正してください。画像処理が端末内であっても、読み取り精度が保証されるわけではありません。

06 / HOME SCREEN

Web版をホーム画面へ追加する

トップページの「血圧記録くん Webを開く」から開きます。この公式紹介サイトではなく、血圧記録くん Web本体を開いた状態で操作してください。

Android・PC

対応するChrome／Edge等のメニューから「ホーム画面に追加」や「アプリをインストール」を選びます。Web版に追加ボタンが表示された場合は、その案内も使えます。名称や表示の有無は環境によります。

iPhone・iPad

Safari等の対応ブラウザでWeb版を開き、共有メニューの「ホーム画面に追加」を確認します。OSやブラウザにより手順が異なります。iPhone実機でのホーム画面追加・カメラ・保存動作の最終確認は未完了です。

追加メニューがない場合も、対応ブラウザからWeb版を利用できることがあります。ホーム画面への追加は、別端末へ記録を同期したり、記録をバックアップしたりする操作ではありません。追加後もCSVの控えを残してください。

07 / OFFLINE

接続がない場所で使う前に

Web版は最初にオンラインで開き、「オフライン利用OK」を確認してから使います。必要なファイルが取得できていれば、主要な記録・履歴・分析・端末内OCRをオフラインで利用できます。ブラウザのキャッシュ消去後や、新しいURLで初めて開く場合は再びオンラインで準備が必要です。

Android版も、記録・振り返り・端末内OCRのためにインターネット接続を必要としません。広告の取得や、クラウド保存先を選んだCSV操作、外部の説明ページの閲覧は別です。
